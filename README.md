# Upstream review branch — TanStack Router source

This branch is **not** part of the POC app. It holds the `src/` trees of
`@tanstack/react-router` and `@tanstack/router-core` exactly as they are on
TanStack Router `main` at commit
[`0caf6b9`](https://github.com/TanStack/router/commit/0caf6b9a2b7e14b0b146c74cc27cb05c19d700a5)
(react-router `1.170.32`, router-core `1.171.27`).

It exists only as the **base** for a pull request, so the PR diff is exactly the
change proposed for upstream. This session cannot fork `TanStack/router`
(cross-owner repositories cannot be attached), so the review happens here
instead of on a fork.
